## 摘要

本文是对 Claude Opus 4.7 完整系统提示词的深度学习笔记，覆盖模型基本信息、核心行为原则、安全与内容限制、格式与语气规范、用户健康与心理安全、政治与价值观立场、法律与金融建议、版权合规、网络搜索行为规范、图片搜索规范、Artifacts 规范、持久化存储 API、Anthropic API 使用、过去对话检索工具、系统提醒机制、错误处理与自我修正、提示词工程建议，以及关键设计哲学总结共十八个模块。

## 核心论点

- Claude 的默认立场是"尽量帮助"，过度谨慎本身也是一种失败
- 对于涉及当今世界的事实性问题，必须先搜索再回答，不能依赖训练数据
- 儿童安全是最高优先级，规则最严格、无例外
- 版权合规有硬性限制：每次引用不超过一定词数，每个来源最多引用一次，歌词/诗歌一行都不能复现
- 格式应服务于理解，而非展示能力，避免过度格式化

## 重要引述

> "过度谨慎本身也是一种失败，拒绝无害请求与帮助有害请求同样是错误。" — 关于默认帮助立场
